01 / Data structures

One shared engine.
Different questions.

The project separates the effect of data structure from the effect of stock-rotation policy, so the comparison stays interpretable.

Explore C source ↗
⌁

Binary Min-Heap · FEFO

Maintains the next eligible batch by expiry date, then received date and batch ID for deterministic tie-breaking. Peek is O(1); insert and extraction are O(log n).

⌕

Hash Table · batch lookup

Supports fast average-case batch-ID lookup and duplicate-ID checks. The data structure is implemented in C rather than delegated to a framework collection.

⇄

Linear FEFO + FIFO baseline

Linear-scan FEFO independently checks the heap's decisions. FIFO models receipt-order issuing so the project can study policy outcomes under the same synthetic event traces.

04 / Workflow

From C source to evidence.

STEP 01

Build

Compile the C11 engine and interactive inventory app with strict compiler warnings.

STEP 02

Verify

Run engine tests, fault-injection checks, sanitizers and isolated app smoke scenarios.

STEP 03

Compare heap vs linear selection and replay identical traces for FEFO vs FIFO.

STEP 04

Explain

Report actual CSV outputs and disclose the limits of synthetic workloads.
